# 游戏牌美术规格 v1

## 完成情况

43 款插画全部生成并加载通过：基本牌 6、锦囊 15、装备 22。逐张核对规则及 160 张实体牌数据与 `catalog.json` 一致。桌面、手机长牌名、关键词最长匹配、红黑花色与牌包切换、弹窗和 Escape 焦点恢复已验证。全部采用插画均为 1024 × 1536，43 张文件内容互不重复。

## 交付文件

- 本地游戏牌图鉴：`http://127.0.0.1:4178/preview/game-cards/`。
- 43 款设计的数据与规则：`data/game-card-art-v1.json`；合计 160 张实体牌，规则、花色、点数和牌包沿用本地 `catalog.json`。
- 原始插画：`assets/art-design/game-cards-v1/`，1024 × 1536 PNG。使用内置 imagegen 生成，插画与 HTML 中文排版分离。
- 实际采用的图片以 JSON 的 `artPath` 为准；【闪电】采用 `shandian-v2.png`，去除了首稿的施法人物，使它与【雷杀】的持刃攻击明确区分。初稿保留。
- 完整提示词：`docs/art/game-cards-v1/prompts/`；通用画风：`docs/art/game-cards-v1/style.prompt.txt`。
- 验证记录：`docs/art/game-cards-v1/verification/`，包括 UI 检查、资产清单与最终加载检查。
- 当前交付为卡牌美术及本地图鉴；Roblox 游戏内导入和技能效果另行接入。

## Scope

本文件覆盖 `catalog.json` 中除身份牌、武将牌以外的 43 张游戏牌：基本牌 6 张、锦囊牌 15 张、装备牌 22 张。这里记录的是 Roblox 三国杀卡面插画规格，不包含 UI 文字排版、花色点数、数量框或实际规则改动。

所有图片输出到 `assets/art-design/game-cards-v1/{id}.png`。牌名、规则描述、花色、点数、数量和专有名词高亮继续由 HTML/游戏 UI 负责，尤其是【杀】、【闪】等规则词，不写进插画里。

## 判断规则

- 基本牌优先用大动作和大符号识别：红斜斩是【杀】，蓝残影是【闪】，粉桃绿光是【桃】，酒坛与青铜杯是【酒】。
- 锦囊牌优先表现规则意向：顺手牵羊是完整取走，过河拆桥是拆除弃置；铁索连环必须有两个锚点；无懈可击是金蓝法印切断锦囊光路。
- 群体锦囊可以出现 2-3 个 Roblox 人物或站位，但不要做拥挤人群，不做血腥。
- 装备牌以单件道具浮空或军械架产品图为主，武器要有独特轮廓，防具是护甲道具而不是武将肖像。
- 坐骑是 7 款独立 Roblox 方块马，靠毛色、姿态、马具和速度/守位语言区分。紫骍使用枣红马体配紫缎饰，爪黄飞电为白身黄蹄，的卢突出白额斑。
- 插画内禁止文字、数字框、花色图标、UI 边框；禁止真人手、LEGO 式夹爪、照搬原作卡图。
