# 武将技能特效第一版

本轮在现有武将模型上演示「杀、闪、桃、万箭齐发」。网页与 Roblox 可操控试演共用 `data/hero-effects-v1.json` 的名称、配色和关键时序。属于美术试播，不结算伤害、回血、牌数或胜负。

| 牌 | 视觉识别 | 演出 |
| --- | --- | --- |
| 杀 | 金橙色轨迹、红色命中 | 根据武器区分刀弧、枪刺、弓箭、重击、扇卡能量；一个明确目标 |
| 闪 | 青色残影 | 短促侧向轨迹和收束，不把角色移出活动范围 |
| 桃 | 玉绿与桃粉 | 脚下光环、向上的花瓣，保持面部清楚 |
| 万箭齐发 | 地面分段预警圈、多个目标点 | 先预警，再错峰箭雨，最后小型落点反馈 |

## 可读性约束

- 用“预示 → 释放 → 命中/消散”分段，颜色之外保留形状与方向差异。
- 特效集中在武器、目标和地面；不使用满屏闪白和镜头震动。
- 万箭齐发的地面圈用于展示此次演出的区域。正式三国杀目标仍须由牌局规则判定，不能把圈内距离直接当成合法目标规则。
- 每名角色同时保留一个演出，重播替换旧特效，换将与结束清理。原生几何不参与碰撞。
- 暂不把临时特效烘焙进 GLB / RBXMX；下载的 Roblox 试演场包含特效运行代码。

## 验证（2026-09-13）

- Chrome WebGL：四种按钮、停止、换将、390×844 页面布局通过；24 次重播后网格缓存和 GPU 上传次数保持稳定，无页面异常。
- Roblox Studio Play：四种特效播放、到期清理、12 次替换重播、停止、换将通过。采样峰值 86 个临时部件，全部无碰撞、触摸和射线查询；生命值保持不变。
- 关羽、赵云、孙尚香、许褚、甄姬分别验证了刀弧、枪刺、弓箭、重击、扇卡分支。孙尚香发射点在释放时读取模型箭杆位置。
- 边界验证：角色靠近活动边缘时，预警圈最远距离不超过 12 studs；客户端传入的伪造目标不被采用。桃试播保持受伤后的生命值 67。
- 证据见 `verification/`。原生手机触控设备、多客户端压力和实际牌局结算未在本轮验证。
