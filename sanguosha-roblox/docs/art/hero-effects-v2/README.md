# 技能印记与特效精修 v2

用户要求：优化简陋的特效，并在使用时于武将头顶闪现对应的技能名字或图案。

## 表现设计

头顶提示使用菱形技能印记：对应名字、独立图案、主色与强调色。进入时短暂放大，停留后轻微上浮淡出；跟随施放者的头部，取消、换将或被下一次特效替换时一起清理。保持四种现有演示 ID 与玩法接口不变。

| ID | 名称 | 新增表现 |
| --- | --- | --- |
| slash | 杀 | 亮刃/箭矢核心、外围拖尾、放射爆点和命中光环；保留不同武器出招形式 |
| dodge | 闪 | 按身体部件构成的人形残影与速度线 |
| heal | 桃 | 花瓣、身体外侧环绕光流与脚下涟漪 |
| arrows | 万箭齐发 | 可辨识箭头、箭雨拖尾及落点爆点/涟漪 |

网页为投影到头部世界位置的 DOM 提示；Roblox 为绑定 Head 的 BillboardGui。网页绘制图标与原生字符图案表达同一类型，不承诺跨渲染器像素一致。未使用外部贴图或新增依赖。

## 接入与范围

`data/hero-effects-v1.json` 的内容版本升级为 2，路径保持兼容；每个 effect 新增 `cue.duration`（显示时长）与 `cue.height`（头部中心上方高度）。`label` 决定名字，`color` / `accent` 决定配色。未来武将技能可沿用这组表现字段；本轮未增加新的技能规则。

只更新美术预览、试演客户端、共享特效表现数据和生成试演场。正式回合、选牌、目标合法性、伤害与技能判定仍由玩法 session 负责。客户端图案不作为规则判断依据。

## 验证

- `browser-report.json`：25 位 × 4 特效 × 3 时间点，头顶提示可见且在默认画框内；取消、到时消失、连续重放缓存稳定；390px 页面检查。
- `browser-effects-report.json`：真实时间播放四种特效，24 次快速交替重放、恢复动作、取消、换将、移动网页布局及页面异常回归。
- `*-release.png` 和 `mobile-arrows.png`：精修后的实际网页截图。
- `browser-cue-qa.cjs`：可从仓库根目录运行的确定性提示检查。Playwright 位置可用 `PLAYWRIGHT_PATH` 指定。
- `studio-report.json`：原生四种提示的头部绑定、文字、到期销毁、3 位武将的替换/取消/换将、有限几何和生命值检查通过；采样峰值为 92 个特效零件。
- `studio-arrow-report.json`：24 个弓箭、384 个箭雨的箭头连接样本通过，最大端点误差约 0.011 studs。
- `build-report.json`：干净目录重建原生试演场逐字节一致，5 个站点产物与源文件一致。
- `online-report.json`：源码提交 `16b640a` 的 Pages 部署成功，5 个线上产物与本地哈希一致。
- `studio-*-qa.luau`：本轮在独立美术试演场 Client 模式执行的检查代码。

网页画面已逐项查看。Studio 现场验证为运行时对象与行为检查；MCP 屏幕捕获返回纯色画面，因此该捕获未作为原生视觉验收证据。

原生手机多人性能及与正式回合的事件时序尚未由本轮美术试演验收覆盖。
