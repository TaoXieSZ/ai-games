# 全牌特效 v3 · 美术预览验收

2026-09-13。覆盖现有 43 种游戏牌：6 基本、15 锦囊、22 装备；共 65 种预览组合。保留原 4 种特效，新增 39 种。网页与 Roblox 试演场共享分类、牌名、颜色、时长配置，各自使用对应平台的几何绘制实现。

## 交互与表现

- 基本牌 / 锦囊牌 / 装备牌分类选择；装备提供「装备入场」「效果触发」。装备入场在角色侧方凝聚轮廓，用光线连接手/胸部；坐骑在脚边出现。两种模式均为临时表现，不修改实际装备。
- 所有牌使用跟随头部的牌名、图案和消散动画；长名称扩大名牌宽度。选择另一张牌、取消或换将均清理旧表现。
- 游戏牌详情提供「预览 3D 特效」，通过 `?effect=<cardId>` 打开对应分类。
- `hero-effects-v1.json` 文件名保持不变，schema 更新为 version 3。保留四个历史别名：sha/slash、shan/dodge、tao/heal、wanjian/arrows；其他 effectId 等于 cardId。

## 验收证据

- `browser-qa.cjs` / `browser-report.json`：65 种组合的多个时间样本、有限矩阵、头顶名牌边界、非空特效绘制、重复播放网格缓存稳定、到时/取消清理、390px 长牌名。抽样最高 92 次特效绘制调用。
- `browser-ui-qa.cjs` / `browser-ui-report.json`：分类按钮 6/15/22、装备模式重播、分类切换清理、手机最后一项装备可点击、游戏牌详情跳转。
- `studio-qa.luau` / `studio-report-*.json`：真实 Studio Play 中完整播放 65 种组合，验证名牌绑定 Head、模式正确、几何有限且无碰撞、角色生命值不变、结束后容器为空；抽样最高 96 个 BasePart。19–65 装备案例在侧方展示改动后重新运行。
- `studio-lifecycle-qa.luau` / `studio-lifecycle-report.json`：非法 ID/模式拒绝、连续替换、提前取消、换将清理和新角色头部绑定。另检查默认锦囊分类的 15 个按钮与滚动容器。
- JS 语法检查及现有 art/catalog 测试通过；原生试演场由源文件重建。`clean-build-report.json` 记录暂存文件独立目录中的重建与一致性校验。

截图 `*-trigger.png`、`*-equip.png` 和 contact-1/2/3.jpg 为网页实画面。原生验证是 Studio 对象、执行和生命周期证据，不代表原生截图视觉验收；此前 MCP 截图路径在 Play 返回纯色，未使用它作为美术证据。

## 接入边界

此轮完成美术预览覆盖，尚未接入正式回合、真实装备变化、判定分支、伤害或手牌操作。群体落点、借刀的二段目标和八卦阵成功判定使用固定样例。浏览器与原生不是逐像素相同的实现；音效、手机原生多人性能和真实对局遮挡仍需结合玩法验收。玩法接入协议见 `../../art-gameplay-handoff.md`。
