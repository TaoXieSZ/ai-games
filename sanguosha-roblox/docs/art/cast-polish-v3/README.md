# 全 25 武将原画对齐精修

目标：逐位对照现有 `assets/art-design/hero-pool-v1/` 原画，精修全部 25 个可动模型，保留 Roblox 方块角色风格；更新网页、GLB、RBXMX 与原生试演场。此轮验收不能以某一位武将或仅构建成功代替全员视觉检查。

## 原因与难点

之前的版本偏重全员骨架、武器握持、动作与导出通路，用共用重甲模板快速覆盖角色。其结果是一些衣饰埋在身体内部、文官仍带武将护甲、曲面发型和布料只剩几个方块。逐位看图和几何调整投入不足是主要原因，并非 Roblox 做不到。

原画含有立体曲面、细密金属纹样、软布与头发、电影光照。当前使用可直接导入的原生 Part/WedgePart 和刚性层级，需要用分面、错层与少量有识别度的纹饰近似曲面；衣袖、裙摆、头发必须绑定到正确肢体并在活动时检查穿插。描绘越细会增加零件、绘制与联网负担，因此优先提升轮廓、配色比例、脸与头饰、服装层次及武器识别，而不是机械增加零件。

## 验证证据与边界

- `before/` 与 `after/`：全员各 3 个视角，共 150 张前后截图；本轮最终画面见 9 张 `contact-*.png` 及分国审阅记录。
- `browser-animation-report.json`：25 位 × 3 动作 × 7 时间样本，模型投影有限且在画框内。
- `export-report.json`：全员源数据相对 `611da85` 改变；25 套 GLB/RBXMX 与两个原生场景部件一致，骨架、连接、附属摆动引用和 3 动作有效。
- `studio-play-report.json`：当前生成的试演场在 Studio Play 中逐位换将、实际行走、出招、闪避；25 位生命值保持 100，60 组附属摆动均发生变化。首次一次性 MoveTo 指令被客户端输入覆盖，测试改为短时连续移动输入后通过；未为使测试通过而修改角色移动代码。
- `studio-connections-report.json`：孙尚香附属摆动与 18 个拉弓样本的弓弦端点、箭轴检查。
- `effects/`：四种既有特效的浏览器生命周期、取消、换将清理、24 次重放缓存稳定性与 390px 页面检查；原生结果另记 `studio-effects-report.json`。
- `clean-build-report.json`：从暂存文件创建独立干净目录，重新设计、导出、生成试演场和站点；53 个产物逐字节一致，清单除生成时间外一致。

原生霓虹材质标识依据 [Roblox Material 枚举](https://create.roblox.com/docs/reference/engine/enums/Material)，浏览器发光与 GLB emissive 同步表达材质意图，三种渲染器画面不承诺像素相同。

此轮完成原生几何模型的全员精修，尚未做软布模拟、电影级贴图或手机原生多人压力测试。黄月英正面机关层次、貂蝉裙袖曲线、大乔背面布料等仍列为后续美术细化项。
